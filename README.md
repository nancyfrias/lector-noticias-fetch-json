# Lector de Noticias

Proyecto desarrollado en HTML, CSS y JavaScript para consumir noticias en tiempo real utilizando AJAX, Fetch y JSON.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- GNews API

## Funcionalidades

- Mostrar noticias en tiempo real
- Actualizar noticias sin recargar página
- Abrir noticia completa
- Manejo de errores
- Diseño responsivo
